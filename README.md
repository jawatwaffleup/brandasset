# WaffleUp Brand Assets

This folder is the portable visual identity library for WaffleUp. Open `preview.html` in a browser to explore the complete, navigable asset collection.

## Brand guidelines

`WaffleUp Brand Guidelines.pdf` is the 63-page visual brand book, built from this library.
Its source is `brand-guidelines/index.html`; run `python brand-guidelines/build.py` to
regenerate the print-weight artwork and re-render the PDF (needs pillow, numpy, scipy and Chrome).

## Contents

- `assets/` — approved logos, icons, symbols, fonts, typography, character artwork, four supplied 3D models, product photography, packaging, event artwork, Surprise Card material and audio.
- `brand/` — core brand, logo, voice and character guidance, plus a placeholder for approved character voices.
- `components/wup-components.css` — reusable WaffleUp visual components.
- `data/characters.json` — the approved Surprise Card descriptions for all ten characters.
- `docs/` — asset catalogue and original brand-reference PDFs.
- `brand-guidelines/` — source for the brand guidelines PDF.
- `tokens/wup-tokens.css` and `tokens/wup-tokens.json` — the visual design tokens used by the preview.

## Character set

Bangladesh has nine canonical characters: Mr Waffle, Air Maxi, Bhoppu, Picchi, Stovy, Swirly, Tvy, Spacy and Icy. Singapore adds Merlulu. Printable 3D models are supplied only for Mr Waffle, Air Maxi, Bhoppu and Picchi.

## Using the assets

Use the brand guides and source files in this folder when creating WaffleUp communications. Preserve the supplied logo artwork and use the canonical character names and descriptions in `data/characters.json`.
