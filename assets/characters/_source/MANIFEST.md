## 5. Transfer — why this is an index and not a mirror

Four routes were tested on 24 Aug 2026:

| Route | Result |
|---|---|
| Anonymous `curl` on the file IDs | **Blocked.** Redirects to Google sign-in — the folder is shared to named accounts, not link-public. |
| Google Drive for Desktop | **Not installed.** Only `C:` and `D:` are mounted. |
| Claude in Chrome (authenticated session) | **No browser connected** to this account. |
| Drive connector `download_file_content` | **Works, but returns base64 through the conversation** — roughly 0.7M tokens per MB round-trip. Fine for a few hundred KB, impossible for 2.7 GB. |

### To mirror the bulk, pick one

**A. Install Google Drive for Desktop** — chosen 24 Aug 2026. Also handles Jeremy's future
updates without another round of this.

```
winget install --id Google.GoogleDrive -e
```

Sign in as jawat@waffleup.global, then in Drive on the web: *Shared with me* →
**WaffleUp_ jeremy** → right-click → *Organise* → *Add shortcut to Drive* → *My Drive*.
It mounts at `G:\My Drive\WaffleUp_ jeremy` (drive letter may differ). Then:

```
python assets/characters/_source/import.py "G:/My Drive/WaffleUp_ jeremy" --dry-run
python assets/characters/_source/import.py "G:/My Drive/WaffleUp_ jeremy"
```

`import.py` matches on basename (so Drive's local folder layout does not matter), renames
everything to brand names on the way in, and is safe to re-run — files already present at
the right size are skipped. It pulls **72 files / 470 MB** and skips the CMYK print set;
add `--cmyk` only when a printer actually needs it.

**B. Download from the Drive web UI.** Right-click the folder → *Download*. Drive will zip it
(expect several parts at this size). Unzip anywhere and point me at the path.

Either way, this is the layout `import.py` writes — brand names, not Jeremy's:

```
assets/characters/_source/
|-- MANIFEST.md         this file
|-- manifest.json       machine-readable index (source of truth for import.py)
|-- import.py           the importer
|-- vector-masters/     10 .ai  - air-maxi.ai ... tvy.ai, family.ai
|-- merlulu/            merlulu.ai + merlulu.psd (universal since 24 Aug 2026)
```
